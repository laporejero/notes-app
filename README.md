# Notes App

## Live Demo: https://notes-app-srlh.onrender.com/

A full-stack notes application built with React, TypeScript, Node.js, Express, and MongoDB. Users can securely register, log in, and manage their own personal notes.

## Features

* JWT Authentication
* User administration and login
* Create, edit, and delete notes
* Pin notes to keep important items at the top
* Mark notes as favorites
* Filter notes by category (All / Favorites)
* Search notes by title and content
* Undo deleted notes
* Responsive layout for desktop, tablet, and mobile devices
* Persistent data storage using MongoDB Atlas
* RESTful API integration between frontend and backend

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* CSS
* Material UI for the Sign in page

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JSON Web Token
* bcrypt

### Tools

* Git
* GitHub
* Render

## What I Learned

This project gave me practical experience designing, building, and deploying a full-stack web application from frontend to backend.

On the frontend, I strengthened my understanding of React, TypeScript, component-based architecture, state management with hooks, controlled forms, conditional rendering, and responsive UI development. I also learned how to organize applications into reusable components and communicate with backend services using Axios.

On the backend, I built RESTful APIs with Express, connected the application to MongoDB Atlas using Mongoose, and implemented CRUD operations for persistent data storage. I also learned how to structure backend routes, validate requests, and design APIs that interact reliably with a React frontend.

One of the most valuable parts of this project was implementing authentication and authorization. I learned how to securely hash passwords with bcrypt, authenticate users using JSON Web Tokens (JWT), protect API routes, and ensure that users can only access and modify their own notes.

Building and deploying the application also taught me how frontend and backend services work together in production. I gained experience configuring environment variables, creating production builds with Vite, deploying a full-stack application on Render, and troubleshooting issues that only appeared after deployment.

Overall, this project strengthened my understanding of full-stack development, REST API design, database integration, user authentication, deployment workflows, and debugging real-world applications.
